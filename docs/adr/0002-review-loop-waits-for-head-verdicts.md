# 리뷰 루프는 켜진 리뷰어 전원의 HEAD 판정을 받은 뒤에만 끝낸다

> ADR 0006 이 이 결정을 개정했다: Minor 이하 수정은 머지 뒤 리뷰 없이 base 로 가고, 대기 상한까지 판정이 없는 리뷰어는 빼고 끝낸다.

리뷰 루프는 그 저장소에서 켜져 있는 리뷰어(CodeRabbit, Codex) 전원이 현재 HEAD 에 판정을 낸 뒤에만 통과로 끝내거나 머지한다. 기다리는 시간에는 상한을 두고, 상한에 걸리면 머지하지 않고 판정이 빠졌다는 사실을 최종 보고에 남긴다. 미룬 지적이 있을 때만 follow-up 이슈를 낸다. 결정 당시 리뷰 루프는 마지막 push 뒤 Codex 리뷰(68-726초, 중앙값 224초)를 30초만 기다렸고 CodeRabbit 의 rate limit 안내를 리뷰 완료로 읽어서, PR #223 과 #269 에서 늦게 도착한 P1 을 놓쳤다.

예외는 ADR 0006 에 모은다.
