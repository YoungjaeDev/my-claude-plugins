# 폼 카피 보이스 가이드

설문/체크리스트 폼 문구의 **제네릭** 톤·표현 규칙. 도메인별 보이스(개발 인테이크 / 강의 상담 등)는 `preset-*.md` 가 제공하고, 이 파일은 어느 폼에나 적용되는 공통 규칙만 둔다. humanize-korean 원칙과 일관한다.

## 톤: 또래 전문가 "협의/선택"

서비스/AI 챗봇 톤 금지. 응답자를 동료로 보고 "함께 고르고 정한다"는 결.

- ✗ `무엇부터 도와드릴까요?`  ✓ 폼 제목은 맥락을 담은 평서 (예: `<프로젝트> 시작 전 확인`)
- ✗ `~해드립니다` 과용  ✓ 담백한 평서·청유 ("골라주세요", "진행합니다")

## 각 문항에 구체 예시

추상적 동작만 적지 말고 괄호로 실제 예시를 붙인다. 응답자가 "이게 뭘 묻는 건지" 바로 알게.

- ✗ `진행 현황 적기`
- ✓ `이번 주 완료 항목 수를 적어주세요 (예: 7/12)`

## 주체는 명시적으로

"시스템이/담당자가/AI가" 같은 익명 주어 대신 실제 주체(서비스명·담당자·역할)를 쓴다. 도메인 주체명은 preset 이 지정한다.

- ✗ `담당자가 정리`  ✓ `<주체>가 정리` (preset 의 주체명으로 치환)

## 인트로는 정확히

과장·미래완료형·"순서대로" 같은 부정확한 약속 금지. 실제로 하는 일을 그대로. 인트로가 길면 빈 줄로 문단을 나눈다(빌더가 문단당 별도 TEXT 블록으로 렌더).

- ✗ `고르신 순서대로 작업에 붙입니다`
- ✓ `골라주신 내용대로 이번 주에 진행합니다`

## 옵션 문구도 자연어

기본 객관식 옵션 = `네, 해주세요 / 나중에 / 설명 듣고 정할게요`. 기계적 "예/아니오" 대신 결정 상태를 자연어로. preset/frontmatter `options` 로 도메인에 맞게 교체 가능.

## 실무 배려 표현 명시

안전·격리·되돌리기 같은 안심 포인트를 문항 안에 드러낸다.

- ✓ `지금은 사본만 공유 (원본은 그대로 두니 안전)`

## anti-AI-slop

humanize-korean 준수:

- 쉼표 과다·번역투·기계적 병렬·당위("결국 사람 손" 류) 배제.
- 청중 눈높이의 일상어 (비개발자 폼이면 "구축/산정/연동" 대신 "만들기/잡기/이어주기").
- 보고서 말투("정밀화합니다") → 발화 호흡의 담백한 한국어.
- 카피를 새로 쓰거나 고칠 때는 SKILL.md 의 humanize 기본 라우팅에 따라 `/humanize-korean:humanize-korean` 으로 윤문(미설치 시 graceful degrade).

## 금지 표현 체크리스트 (빌드·리뷰 시 0건이어야 함)

| 패턴 | 이유 | 대안 |
|------|------|------|
| `도와드릴까요` | 서비스/챗봇 톤 | 협의·선택 평서·청유 |
| `~해드립니다`(과용) | 과공손·AI 티 | 담백한 평서 ("진행합니다", "올립니다") |
| 빈 추상 문항 (예시 없음) | 응답자가 이해 못 함 | 괄호 구체 예시 추가 |
| 익명 주어 ("시스템이/담당자가") | 주체 모호 | preset 의 실제 주체명 명시 |
