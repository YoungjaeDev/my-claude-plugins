## Subagents (not installed by `codex plugin add`)

Codex `plugin.json` has no `agents` field, so these Claude Code subagents are
not bundled. To use them in Codex, run the user-mode bridge sync
(`node plugins/codex-bridge/scripts/sync.mjs`), which writes them to
`~/.codex/agents/<plugin>-<agent>.toml`.
