# 프리셋: 강의 / 코칭 상담

강의·코칭·클래스 수강 상담 신청 설문 보이스 + 스켈레톤. 바로 빌드 가능한 예시는 `assets/example-lecture-consultation.md`.

## 주체 / 톤

- 주체 = 강사/코치 본인 또는 운영팀(예: "제가", "운영팀이"). 익명 주어 금지.
- 톤 = 부담 없이 시작하게 하는 따뜻한 평서. 과공손(`~해드립니다`) 회피.
- 수준·목표 문항은 응답자가 자기 상태를 쉽게 고르도록 자연어 선택지.

## 기본 옵션

관심·의향을 묻는 폼이므로:

```
options:
  - 네, 관심 있어요
  - 더 알아보고 싶어요
  - 아직 모르겠어요
```

## 섹션 스켈레톤

1. **신청자 소개** (`### ` 자유 입력) — 이름/닉네임, 연락 방법.
2. **관심 분야·동기** (`## ` 객관식 + `### ` 자유) — 어떤 주제, 왜 배우려는지.
3. **현재 수준** (`## ` 객관식) — 입문/경험 있음 등 단계.
4. **희망 일정** (`%%date` / `%%matrix`) — 상담 가능 날짜·요일×시간대.
5. **목표·메모** (`### ` 자유 입력) — 이 강의로 이루고 싶은 것.

## 문항별 보기 · 단답 · 필수 동의 (선택)

전역 옵션과 다른 보기·필수 동의·단답이 필요한 문항은 directive 로(상세 `references/tally-blocks.md`):

```markdown
%%phone label: 연락받을 번호 (required) (placeholder: 010-0000-0000)
%%choice
title: 개인정보 수집·이용 동의
options: 동의합니다
select: single
required: true
desc: 상담 연락을 위해 연락처를 수집합니다
%%
```
